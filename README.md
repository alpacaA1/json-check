# Tool Hub

本机工具、项目、静态原型和资料目录的统一入口。

## 启动

双击 `start.command`，或在当前目录执行：

```bash
node server.js
```

然后访问：<http://127.0.0.1:3460>

## 特点

- 零外部依赖，只使用 Node.js 内置模块。
- 从 `tools.json` 读取白名单入口，不接受任意 Shell 命令。
- 可检测项目路径、依赖、Git 状态和本地服务端口。
- 本地服务未运行时可以启动并打开，已运行时直接进入；由 Tool Hub 启动的服务可查看日志并安全停止。
- 静态原型通过 Tool Hub 本地预览，支持中文路径和相对资源。
- 候选扫描只保留项目根目录，自动跳过已收录项目和常见生成目录。
- 不自动安装依赖，不关闭未知端口进程。

## 管理入口

右上角“添加入口”可直接收录新项目：

- 选择“扫描后收录”可从候选项目中回填路径、类型和静态入口文件。
- 选择“手动填写”可添加本地服务、静态页面、资料目录或 Chrome 扩展。
- 提交时会检查本地路径、静态入口、服务端口和启动程序，并将结果写入 `tools.json`。

复杂操作、多个启动动作或已有入口的细粒度调整，仍可直接修改 `tools.json` 后刷新页面。路径支持：

- `{hubRoot}`
- `{workspaceRoot}`
- `{documentsRoot}`
- `{downloadsRoot}`

## 验证

```bash
node --test server.test.js
```

运行日志保存在系统临时目录 `tool-hub-runtime` 下。
